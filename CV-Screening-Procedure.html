Hard requirements
релевантный опыт (кол-во лет, стек, домен)
ключевые навыки, указанные в JD
уровень английского / языка
наличие обязательных сертификатов
Отсутствие любого обязательного критерия → reject.
Soft requirements
структурированность резюме
логичность карьерного пути
стабильность (без частых переходов)
мотивация, отражённая в профиле
Используются для приоритизации кандидатов.
Red flags
несоответствие опыта заявленному уровню
частые увольнения < 6 месяцев
отсутствие ключевых навыков
неполные или противоречивые данные
Наличие 2+ red flags → reject или manual review.
Decision Matrix
Проходит
• Все hard requirements выполнены
• Нет red flags
• Soft skills соответствуют уровню
Отказ
• Нет обязательного навыка
• Опыт < минимального порога
• 2+ red flags
Manual review
• Частичное соответствие hard skills
• Сомнительная стабильность
• Нестандартный профиль
